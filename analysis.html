HU Lifestyle Survey

Collecting the Data

I collected 42 pieces of 100% human data (this is not a joke I did not use AI) by creating a QR code and walking up to strangers and pleading with them to fill out the form.

Was there probably an easier way of getting responses? ...yes, but It was very enjoyable to run around with a QR code so my method stands.

Analysing the Data

The data was put into Excel and sorted using __IFS formulas. However, as I am writing this I am realizing it would have been a lot simplier to simply copy the data and then use the regular formulas instead of using AVERAGEIF.

Regardless, I took different sections of the data and compared them against each of the halls to see if any patterns emerged, which we will see as we move to the graphs.
